# Настройка GREEN-API

Чтобы приложение отправляло и получало сообщения, нужен **инстанс GREEN-API**: подключение одного аккаунта
мессенджера. Один инстанс обслуживает один мессенджер и один номер, поэтому для каждого таба (MAX, Telegram,
WhatsApp) нужен свой инстанс со своими ключами.

## 1. Создать инстанс

Публичного тестового токена или песочницы у GREEN-API нет, поэтому для проверки нужен собственный инстанс.

1. Заведите аккаунт мессенджера. Для MAX номер регистрируется в официальном мобильном приложении: веб-версия
   для регистрации не подходит.
2. Зарегистрируйтесь в [личном кабинете GREEN-API](https://console.green-api.com).
3. Создайте инстанс нужного мессенджера. Для проверки хватит бесплатного тарифа **Developer**. Его
   ограничения: 3 чата и 100 проверок номеров, для MAX — 1 инстанс на аккаунт. При превышении API отвечает
   ошибкой 466. Новый инстанс активируется в течение пары минут.
4. Авторизуйте инстанс аккаунтом мессенджера:
   - **MAX:** сначала **отключите пароль для входа в MAX**, иначе авторизация не пройдёт. Затем в приложении
     откройте Профиль → Устройства → Вход по QR-коду и отсканируйте QR-код из личного кабинета;
   - **Telegram:** QR-код или код из SMS;
   - **WhatsApp:** QR-код в приложении WhatsApp.

   После этого состояние инстанса станет **authorized**.

> Для полного сценария нужен второй номер с аккаунтом в том же мессенджере: на него приложение отправляет
> сообщение, и с него приходит ответ.

## 2. Взять учётные данные

В карточке инстанса есть три значения, которые вводятся в форму входа приложения:

| Поле в приложении | Где взять | Пример |
|---|---|---|
| `idInstance` | ID инстанса | `3100123456` |
| `apiTokenInstance` | API token | `a1b2c3…` (длинная строка из букв и цифр) |
| `apiUrl` | API URL (необязательно) | `https://3100.api.green-api.com` |

Если оставить `apiUrl` пустым, приложение вычислит его по первым 4 цифрам `idInstance`. Если вход не проходит
с ошибкой связи, скопируйте `apiUrl` из личного кабинета.

## 3. Включить уведомления

Сообщения приходят через **HTTP API** (`receiveNotification`), поэтому в настройках инстанса должно быть:

| Настройка | Значение | Зачем |
|---|---|---|
| `webhookUrl` | **пусто** | пока задан вебхук, HTTP API уведомлений не отдаёт |
| `incomingWebhook` | `yes` | входящие сообщения |
| `outgoingWebhook` | `yes` | статусы доставки и прочтения |
| `outgoingMessageWebhook` | `yes` | сообщения, отправленные с телефона |

В новом инстансе уведомления выключены. Приложение проверяет это при входе и предлагает **«Включить
и войти»**. После этого инстанс перезапустится, а настройки применятся в течение ~5 минут. Те же флаги можно
выставить вручную в личном кабинете.

## 4. Проверить

1. Откройте приложение: https://anrb13.github.io/message-sender/ или `npm run dev`.
2. Выберите таб мессенджера и войдите с `idInstance` и `apiTokenInstance`.
3. Введите номер собеседника и создайте чат.
4. Отправьте сообщение и ответьте на него с телефона собеседника. Ответ появится в чате.

## Частые проблемы

| Симптом | Причина и решение |
|---|---|
| «Неверный idInstance или apiTokenInstance» | опечатка в ключах или неверный `apiUrl`. Скопируйте значения из личного кабинета |
| «Инстанс не авторизован» | инстанс не привязан к аккаунту мессенджера. Пройдите авторизацию в личном кабинете |
| «Инстанс запускается» | инстанс перезапускается, например после смены настроек. Подождите пару минут |
| «Не удалось связаться с GREEN-API» | нет сети или неверный `apiUrl` |
| «Номер … не зарегистрирован в …» | у номера нет аккаунта в этом мессенджере, или номер введён без кода страны |
| «Исчерпан лимит тарифа» (466) | закончились чаты или проверки номеров на тарифе |
| В сайдбаре «задан webhookUrl» | очистите `webhookUrl` в настройках инстанса |
| Сообщения уходят, но ответы не приходят | выключен `incomingWebhook`: войдите заново и нажмите «Включить и войти» или включите его в личном кабинете. После включения подождите до 5 минут |
| Не обновляются статусы ✓✓ | выключен `outgoingWebhook` |

> `apiTokenInstance` хранится только в `localStorage` вашего браузера и отправляется только в GREEN-API.
> Кнопка «Выйти» удаляет его вместе с перепиской этого мессенджера.
